# Cyber Threat Identification

## Objective

The objective of this project is to recognize common cybersecurity threats and understand their targets, potential impacts, and prevention methods.

## Threats Covered

- Phishing
- Malware
- Ransomware
- Social Engineering
- Credential Theft

## Tools Used

- Web Browser
- Google Docs
- GitHub
- Free cybersecurity resources

## Threat Classification

| Threat | Target | Impact | Prevention |
|---|---|---|---|
| Phishing | Individuals, employees, organizations | Credential theft, financial loss, malware infection | Verify the sender, avoid suspicious links, use email filtering and multi-factor authentication |
| Malware | Computers, mobile devices, networks | Data loss, system damage, unauthorized access | Use security software, keep systems updated, download files only from trusted sources |
| Ransomware | Individuals, businesses, organizations | File encryption, business disruption, financial loss | Maintain offline backups, patch systems, use security software, avoid suspicious attachments |
| Social Engineering | Employees, customers, individuals | Unauthorized access, information disclosure, financial loss | Verify requests, provide security awareness training, follow verification procedures |
| Credential Theft | User accounts, employees, online services | Account takeover, data breaches, identity misuse | Use strong unique passwords, password managers, and multi-factor authentication |

## Approach

The project was completed by identifying common cybersecurity threats and classifying them based on their targets, potential impacts, and prevention methods.

The information was organized into a structured threat classification table for easy understanding.

The project provides a structured classification of five common cybersecurity threats and explains their targets, impacts, and basic prevention methods.

## Interview Questions

### What is phishing?

Phishing is a cyberattack in which attackers use fraudulent messages, emails, or websites to trick people into revealing sensitive information or performing unsafe actions.

### What is ransomware?

Ransomware is a type of malware that typically encrypts files or systems and demands payment from the victim.

### What is social engineering?

Social engineering is the use of psychological manipulation or deception to trick people into revealing information or performing an action.
