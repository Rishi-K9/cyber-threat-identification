Cyber Threat Identification

Objective

The objective of this project is to recognize common cybersecurity threats and understand their targets, potential impacts, and prevention methods.

Threats Covered

1. Phishing
2. Malware
3. Ransomware
4. Social Engineering
5. Credential Theft

Tools Used

1. Web Browser
2. Google Docs
3. GitHub
4. Free cybersecurity resources

Project Outcome

This project provides a structured classification of common cybersecurity threats based on their targets, impacts, and prevention methods.
