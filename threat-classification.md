# Cyber Threat Classification

## Objective

The objective of this classification is to identify common cybersecurity threats, their targets, potential impacts, and prevention methods.

## Threat Classification Table

| Threat | Target | Impact | Prevention |
|---|---|---|---|
| Phishing | Individuals, employees, organizations | Credential theft, financial loss, malware infection | Verify the sender, avoid suspicious links, use email filtering and multi-factor authentication |
| Malware | Computers, mobile devices, networks | Data loss, system damage, unauthorized access | Use security software, keep systems updated, download files only from trusted sources |
| Ransomware | Individuals, businesses, organizations | File encryption, business disruption, financial loss | Maintain offline backups, patch systems, use security software, avoid suspicious attachments |
| Social Engineering | Employees, customers, individuals | Unauthorized access, information disclosure, financial loss | Verify requests, provide security awareness training, follow verification procedures |
| Credential Theft | User accounts, employees, online services | Account takeover, data breaches, identity misuse | Use strong unique passwords, password managers, and multi-factor authentication |
